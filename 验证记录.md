## 3. 生产者与三个消费者（curl）
```
$ curl -s -X POST http://localhost:3001/api/v1/business/sign-contract -H 'Content-Type: application/json' -d '{}'
{"ok":true,"event_type":"contract.signed","event_id":"evt_65624e78993d720d","stream_id":"1795497139650-7"}

$ curl -s -X POST http://localhost:3001/api/v1/consume/all -H 'Content-Type: application/json' -d '{"sample":"contract.signed"}'
[{"consumer":"sop_dispatch","ok":true,"kind":"sop_todo"},
 {"consumer":"room_status_update","ok":true,"kind":"room_snapshot"},
 {"consumer":"payment_plan_generation","ok":true,"kind":"payment_plan"}]
```
合同签署事件被三个消费者各处理 1 次，`GET /api/v1/consumers` 的处理记录含 consumer / event_id / event_type / outcome，自动化测试按此断言。

## 4. 未知字段与死信队列（curl）
```
$ curl -s -X POST http://localhost:3001/api/v1/consume/all -H 'Content-Type: application/json' -d '{"sample":"unknown_fields"}'
{"all_ok":true,"count":3}

$ curl -s -X POST http://localhost:3001/api/v1/consume/all -H 'Content-Type: application/json' -d '{"sample":"missing_org_id"}'
[{"ok":false,"reason":"$.org_id: missing required property"},
 {"ok":false,"reason":"$.org_id: missing required property"},
 {"ok":false,"reason":"$.org_id: missing required property"}]

$ curl -s http://localhost:3001/api/v1/dlq
{"count":3,"first_reason":"$.org_id: missing required property"}
```
带未知字段的事件被三个消费者正常处理、死信队列为空；缺少 org_id 的事件被拒绝进入死信队列且 reason 非空。批量投递（`POST /consume/batch`）中坏事件之后的合法事件仍被三个消费者各处理 1 次，由自动化测试断言。
